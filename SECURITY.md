# Security policy

## Reporting a vulnerability

Please email **[support@lintsure.com](mailto:support@lintsure.com)** with "Security" in the subject. Include what you found, how to reproduce it, and the version or commit.

Please don't open a public GitHub issue for a security problem. We'll reply to confirm we received it and keep you updated until it's resolved.

## Supported versions

Lintsure is at version 0.1. Fixes go into the latest version on the `main` branch.

## What Lintsure does with your code

The engine reads files on your machine and makes no network calls; a test enforces this. See [Privacy and security](https://lintsure.com/docs/privacy-security) in the docs.
