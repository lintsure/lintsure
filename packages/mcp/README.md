# @lintsure/mcp

Lintsure as an MCP server for Claude Code, Cursor, Codex, Devin Desktop (formerly Windsurf) and other MCP clients. Runs on your machine over stdio, never writes files, never uploads your code.

> **Lintsure is a readiness tool, not an audit, a certification or legal advice.** It tells your coding agent not to call you compliant, certified or ready, not to decide for you, and to ask before changing anything. A person makes the final call.

```bash
claude mcp add lintsure -- npx -y @lintsure/mcp
```

Then ask your agent: *check this repo for compliance*.

Tools: `scan`, `classify`, `explain_framework`, `explain_rule`. Setup for Cursor, Codex and Devin Desktop (formerly Windsurf): https://lintsure.com/docs/mcp
